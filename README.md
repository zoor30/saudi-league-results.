# عزبة نجد — Ezbat Najd

نموذج أولي للعبة مزرعة/عزبة سعودية ثلاثية الأبعاد مصممة للجوال بوضع عمودي.

## النسخة الحالية
- عالم 3D قابل للسحب والتقريب.
- 9 نجديات سود + فحل بحركة مستقلة.
- حالات تجول، أكل وشرب.
- معلف، حوض ماء، مشمع، شبك، برسيم/تبن ووايت قديم.
- واجهة عربية عمودية وأزرار تفاعل.

> المشروع تجريبي ويتم تطوير هويته البصرية وأسلوب اللعب تدريجيًا.
